# 🚀 Mission: Save Pixel the Bear! (What If...? Conditionals)

> **5-Minute Interactive Demo Teaching Presentation for Timedoor Coding Academy**  
> **Candidate:** Rafly A.R.  
> **Topic:** Beginner 1 — Meeting 5: Conditionals (`IF - ELSE`)  
> **Aesthetics:** 2D Arcade / Nintendo Pop with official **[Kenney](https://kenney.nl)** Game Assets (CC0) and authentic **Scratch 3.0** visual blocks.

---

## 🎮 Live Interactive Presentation
- **Web App Presentation:** Open `index.html` or `slides_presentation.html` in any modern web browser.
- **Presenter Mode (Teleprompter & Timer):** Press **`S`** to reveal the 5:00 countdown stopwatch and word-for-word spoken English script with teacher cues.
- **Fullscreen Mode:** Press **`F`**.
- **Sound Effects:** 8-bit retro Web Audio synthesizer built-in (toggle with **`M`**).
- **Interactive Mechanics:**
  - **Level 1 (Warm-Up):** Real-life gamer reaction challenge (IF Blue -> Raise hand, ELSE -> Friendly wave).
  - **Level 2 (Weather Dilemma):** Real-world logic decision (Rain -> Umbrella vs Sunny -> Sunglasses).
  - **Level 3 (Scratch Bridge):** Visual C-block logic and the River Dilemma (Why we need `ELSE`).
  - **Level 4 (Mystery Cards):** Interactive 3D flip card game! Click Card A and Card B to execute code rules.
  - **Level 5 (Victory):** Golden star badge and virtual high-five celebration!
